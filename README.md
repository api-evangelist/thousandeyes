ThousandEyes is Cisco's digital experience monitoring platform, acquired in 2020 and operated as part of Cisco Networking. It runs a global fleet of cloud, enterprise and endpoint agents that measure network paths, BGP routing, application response and internet outages end to end, and exposes that telemetry through the ThousandEyes v7 REST API. The v7 API is documented on Cisco DevNet and backed by generated SDKs for Python, Go and Java, a CLI, and a Terraform provider. Cisco publishes no anonymously fetchable OpenAPI document for it: api.thousandeyes.com/openapi.json answers 401 rather than 404, so the contract exists but is gated behind credentials.

## Ownership

Part of the Cisco family (acquired 2020).

## Contract status

A machine-readable contract exists but is credential-gated (the spec endpoint answers 401, not 404). API Evangelist has not authored a substitute.
